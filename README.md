# Ucapan Selamat

Website statis untuk GitHub Pages.

## Menjalankan di GitHub Pages

1. Upload seluruh isi folder ini ke repository GitHub.
2. Buka **Settings > Pages**.
3. Pada **Build and deployment**, pilih **Deploy from a branch**.
4. Pilih branch utama (biasanya `main`) dan folder `/ (root)`, lalu klik **Save**.
5. Buka URL Pages yang diberikan GitHub.

File `.nojekyll` sudah disertakan agar GitHub Pages menyajikan aset statis dan folder halaman secara langsung.
